## 组件说明

### 1. 前端层 (Streamlit)

- **Streamlit 应用**: Python Web 框架
- **功能**:
  - 产品设计图生成
  - 商品说明文生成
  - LP 落地页生成
  - 图片背景修正
  - 向量搜索

### 2. AI 能力层

| 能力 | 华为云服务 |
|------|-----------|
| 文本生成 | MaaS (DeepSeek-V4-Flash / GLM-5.2) |
| 图像生成 | MaaS (Qwen-Image) |
| 向量嵌入 | MaaS (BGE-M3) |
| 翻译 | 机器翻译服务 |

### 3. 数据层

| 组件 | 用途 |
|------|------|
| OBS | 图片存储 |
| CSS | 向量检索 |
| GaussDB | 结构化数据 |

---

## 数据流

1. 用户访问 Streamlit 应用
2. 选择使用场景（图像生成/文本生成等）
3. 调用 MaaS API（DeepSeek-V4-Flash / Qwen-Image / BGE-M3）
4. 结果存储到 OBS/CSS
5. 返回展示给用户

---

## 安全

- IAM 身份认证
- KMS 密钥加密
- VPC 网络隔离
